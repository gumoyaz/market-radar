# Breakout Logic V2

## 본 문서의 위치
이 문서는 본 프로젝트의 2단계(Candidate Scoring) 내부 구조를 정의한다.
본 프로젝트의 1단계(Market Regime Judgment)는 별도이며, 1단계 결과가
이 문서의 컷오프와 가중치를 바꾼다. 자세한 구조는 PROJECT_SCOPE.md 참조.

## 정의

`Breakout Logic V2`는 돌파매매를 두 프레임으로 나눠서 보는 방식이다.

1. `테일분뉴 프레임`
미모사의 `테일분뉴`를 바탕으로 종목의 기본 적합도를 본다.

- 테마
- 일봉
- 분봉
- 뉴스

2. `실행 프레임`
테일분뉴 프레임을 통과한 종목을 실제 매수/관망/제외로 나누는 실행 판단 로직이다.

핵심은 다음과 같다.

- 테일분뉴 프레임은 `좋은 종목`을 고른다
- 실행 프레임은 `좋은 자리`를 고른다

## 왜 실행 프레임이 필요한가

테일분뉴만 좋다고 바로 매수하면 안 되는 이유는 분명하다.

- 테마와 일봉은 좋은데 분봉 자리가 이미 멀 수 있다
- 뉴스는 강한데 그 순간은 과열 자리일 수 있다
- 돌파는 좋아 보여도 오늘 시장 자체가 함정장일 수 있다
- 같은 돌파라도 시도, 안착, 실패를 구분해야 한다

즉, 테일분뉴 프레임 적합도와 실행 프레임 실행 가능성은 분리해서 봐야 한다.

## 테일분뉴 프레임 요약

테일분뉴 프레임은 [TEILBUNNYU_SCORECARD.md](C:/Users/Vince-PC/Documents/Codex/market-radar/docs/TEILBUNNYU_SCORECARD.md)를 따른다.

테일분뉴 프레임에서 보는 것:

- 테마가 살아 있는가
- 일봉이 신고가/장기 횡보 돌파 자리인가
- 분봉에 거래대금이 붙는가
- 뉴스가 있고 강한가

테일분뉴 프레임 출력:

- `Theme score`
- `Daily score`
- `Minute score`
- `News score`
- `테일분뉴 총점`

## 실행 프레임 핵심 질문

실행 프레임은 아래 질문에 답해야 한다.

1. 지금 돌파가 `시도` 단계인가, `안착` 단계인가
2. 이미 너무 멀리 가서 추격 리스크가 큰가
3. 거래대금이 `순간 스파이크`인가, `지속 유입`인가
4. 프로그램/수급이 받쳐주는가
5. 오늘 시장 자체가 이 돌파를 허용하는가
6. 같은 테마 안에서 진짜 주도주인가

## 실행 프레임 구성

### A. Breakout Stage

현재 분봉 위치를 아래 단계로 나눈다.

- `wait`
  - 아직 당일 고가와 거리가 있고 거래대금도 부족
- `probing`
  - 당일 고가 근처에서 돌파를 시도 중
- `breaking`
  - 당일 고가를 막 돌파하는 순간
- `holding`
  - 돌파 후 고가 위에서 유지 중
- `extended`
  - 돌파는 맞지만 이미 많이 올라 추격 부담이 큼
- `failed`
  - 돌파 시도 후 레벨을 지키지 못함

실전 해석:

- `probing`은 관찰 구간
- `breaking`과 `holding`은 실행 검토 구간
- `extended`는 추격 주의
- `failed`는 즉시 제외

### B. Liquidity Persistence

거래대금은 `기준 충족`보다 `지속 유지`가 더 중요하다.

현재 기본 기준:

- 소형주: 분당 거래대금 30억 이상
- 중형 이상: 분당 거래대금 60억 이상
- 최소 3분 이상 유지

실전 해석:

- 1분만 튀는 거래대금은 낚시일 수 있다
- 3분 이상 유지되면 실제 수급 유입일 가능성이 높다
- 같은 돌파라도 거래대금 지속 여부가 성패를 가른다

### C. Leadership

같은 테마 안에서 대장주/주도주 여부를 함께 본다.

핵심 항목:

- 테마 내 거래대금 순위
- 테마 내 상승률 순위
- 뉴스 중심성
- 선두 유지 시간

실전 해석:

- 속도만 빠른 종목은 가짜 선두일 수 있다
- 돈만 큰 종목은 무거울 수 있다
- `돈 + 속도 + 지속성`이 같이 붙는 종목이 최우선이다

### D. Market Fit

실행 프레임은 종목만 보지 않고 오늘 시장의 허용 범위도 같이 본다.

핵심 질문:

- 오늘은 첫 돌파가 잘 먹히는가
- 오늘은 재돌파가 더 좋은가
- 오늘은 추격보다 눌림이 유리한가
- 오늘은 함정 비율이 높은가

즉, 같은 종목이라도 1단계 시장 판정 결과에 따라 `actionable`이 될 수도 있고 `watch`로 내려갈 수도 있다.

### E. News Timing

뉴스는 존재 여부만이 아니라 타이밍까지 함께 본다.

핵심 질문:

- 장중 새 뉴스인가
- 이미 소화된 오래된 뉴스인가
- 테마와 정렬되는가
- 해당 종목이 직접 수혜주인가

## 실행 프레임 최종 분류

실행 프레임은 최종적으로 아래처럼 분류한다.

### actionable

- 테일분뉴 프레임 점수 좋음
- 돌파 상태가 `breaking` 또는 `holding`
- 거래대금 3분 지속
- 시장도 그 돌파를 허용함

### stalk

- 종목은 좋음
- 아직 `probing` 단계거나 거래대금이 한 템포 부족
- 조금 더 확인 후 진입 가능

### watch

- 관심은 가지만 아직 근거가 약함
- 테일분뉴 프레임 또는 실행 프레임의 일부가 부족

### too_extended

- 돌파는 맞는데 이미 멀리 감
- 추격 리스크가 큼

### avoid

- 돌파 실패
- 거래대금 미달
- 뉴스/테마/시장 상태가 비우호적

## 추천 운영 방식

0. [시장 판정 / 1단계] 오늘 시장이 돌파 우호장인지 확인. 함정장이면 진입 자체를 보수적으로 본다.
1. 테일분뉴 프레임으로 종목 적합도 점수 계산
2. 적합도 미달 종목 제거
3. 남은 종목에 실행 프레임 적용
4. 1단계 시장 판정 결과로 actionable 컷오프와 가중치를 조정
5. actionable / stalk / watch / too_extended / avoid 분류
