# Project Scope

## 한 줄 정의

`Market Radar`는 한국 주식 단기 트레이딩에서 "최근 시장이 어떤 전략을 허용하는지"를 분석하는 시장 분위기 분석 앱이다.

## 핵심 목표

이 프로젝트의 1차 목표는 아래를 숫자로 보여주는 것이다.

- 최근 1주일 돌파매매 성공률
- 최근 시장이 돌파 친화적인지, 함정이 많은지
- 어떤 시간대와 어떤 돌파 패턴이 유리한지

즉, 종목 추천보다 먼저 `전략 선택`과 `시장 해석`을 돕는 도구가 되는 것이 목표다.

## 현재 페이즈

현재 페이즈의 범위는 의도적으로 좁게 잡는다.

- 돌파매매 로직 설계
- 돌파매매 인터페이스 설계
- 최근 돌파 트렌드 분석
- 돌파 친화장 / 함정장 같은 시장 상태 해석

현재는 여러 전략을 동시에 완성하는 것보다, `돌파매매 하나를 제대로 구조화하는 것`이 우선이다.

## 현재 중점 전략

- 돌파매매

## 다음 페이즈 전략

- 눌림목
- 종베매매
- 상따매매
- 스윙

## 포함 범위

현재 범위에 포함되는 것:

- 분봉/일봉/거래대금/프로그램 매수 기반 분석
- 돌파 이벤트 정의와 성공/실패 라벨링
- 최근 5일 / 20일 / 60일 돌파 성과 집계
- 시간대별 돌파 패턴 성과 분석
- 시장 상태 분류
- HTML/JSON 대시보드
- 키움 기반 실시간/준실시간 수집 연결

## 비포함 범위

현재는 아래를 최우선 범위로 두지 않는다.

- 완전 자동매매
- 초단타 체결 최적화
- 주문 체결 엔진 고도화
- 멀티 전략 동시 완성
- 딥러닝 기반 예측 모델 우선 개발

즉, 1차 단계에서는 `돌파매매 분석기`와 `시장 상태 해석기`가 중심이다.

## 성공 기준

프로젝트가 유의미하다고 볼 기준:

- 최근 1주일 돌파매매 성공률을 자동 집계할 수 있다
- 최근 시장이 돌파에 우호적인지 설명할 수 있다
- 시간대별/패턴별 돌파 성과 차이를 보여줄 수 있다
- 사용자가 장중 판단 전에 "오늘 돌파가 되는 장인지" 참고할 수 있다

## 사용자 관점 출력

현재 페이즈에서 사용자가 봐야 할 핵심 출력:

- 오늘 시장 상태: `돌파 우호 / 중립 / 함정`
- 최근 1주일 돌파매매 성공률
- 최근 1주일 돌파매매 평균 기대수익
- 시간대별 유리한 돌파 패턴
- 최근 잘 되는 돌파 유형
- 피해야 할 돌파 유형

## 개발 우선순위

1. 돌파매매 진입/성공/실패 정의 고정
2. 돌파매매 이벤트 라벨링 규칙 정리
3. 돌파매매 중심 통계 집계
4. 돌파매매 인터페이스 설계
5. 시장 상태 해석 로직 정리
6. 다음 전략 확장 기반 마련
