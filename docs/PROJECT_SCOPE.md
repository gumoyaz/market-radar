# Project Scope

## 한 줄 정의

`Market Radar`는 한국 주식 단기 트레이딩에서 **시장 분위기를 실시간으로 판정하고, 그 결과를 토대로 진입 가능한 종목을 추려주는 분석 도구**다.

## 핵심 목표

이 프로젝트는 두 질문에 동시에 답하는 것이 목표다.

1. 지금 시장이 어떤 매매 전략을 허용하는가? (시장 판정)
2. 그 시장 안에서 실제로 진입할 만한 종목은 무엇인가? (종목 선별)

이 둘은 분리된 모듈이 아니라 **2단계 파이프라인**으로 묶여서 작동한다.

## 2단계 파이프라인

```
[1단계] Market Regime Judgment
   - 전략별 시장 상태를 정량화
   - 출력: 우호장 / 중립 / 함정장

   → 이 결과가 2단계의 임계값과 가중치를 바꾼다

[2단계] Candidate Scoring
   - 1단계 regime을 입력으로 받아 컷오프 조정
   - 종목별 점수와 액션 라벨 산출
   - 출력: actionable / stalk / watch / too_extended / avoid
```

핵심 원칙:

- 1단계 없이 2단계는 의미 없다. 함정장에서 점수만 보고 진입하면 손실로 이어진다.
- 1단계는 워치리스트 평균이 아닌 **시장 전체 기준의 자동 집계 통계**여야 한다.
- 1단계 결과는 가산점이 아니라 **2단계의 actionable 컷오프 자체를 움직여야 한다.**

## 현재 페이즈 (Phase 1)

현재는 위 2단계 구조를 **돌파매매** 하나로 먼저 끝까지 만든다.

다른 전략을 동시에 만들지 않는 이유는, 한 전략에서 1단계 → 2단계 결합이 정상 작동하는 것을 먼저 검증해야 다음 전략을 같은 틀로 복제할 수 있기 때문이다.

### Phase 1 산출물

1단계:

- 돌파 이벤트 자동 라벨링 규칙
- 최근 N일 돌파 성공률 자동 집계
- 시간대별 돌파 성공률 / 함정률
- 첫 돌파 vs 재돌파 우세도
- 시장 상태 분류기 (`돌파 우호 / 중립 / 함정`)

2단계:

- 미모사식 1차 프레임 (테마/일봉/분봉/뉴스)
- 2차 실행 프레임 (Stage / Liquidity / Leadership / Market Fit / News-Timing)
- 1단계 regime을 받아 컷오프와 가중치를 조정하는 결합 로직
- 종목별 actionable / stalk / watch / too_extended / avoid 라벨

## 다음 페이즈 — 다전략 확장

같은 2단계 구조를 다른 매매법으로 복제한다.

### 확장 전략

- 눌림목
- 상따
- 종베
- 스윙

### 전략별 1단계 (시장 판정)

각 전략마다 별도의 1단계가 붙는다.

- 돌파 우호장 / 함정장
- 눌림목 우호장 / 함정장
- 상따 우호장 / 함정장
- 종베 우호장 / 함정장
- 스윙 우호장 / 함정장

같은 날 한 전략은 우호장이고 다른 전략은 함정장일 수 있다. 전략별 1단계는 독립적으로 판정되어야 한다.

### 전략별 2단계 (종목 선별)

각 전략마다 진입 조건과 성공/실패 정의가 다르므로 2단계 로직도 전략별로 다르다. 단, 인터페이스(입력/출력 형식)는 공통이어야 다음 전략 추가 비용이 낮아진다.

### Phase 2 산출물

- 전략별 1단계 / 2단계 모듈
- 전략 간 비교 대시보드 (오늘 어떤 전략이 살아 있는가)
- 전략별 추천 종목 카드
- 시장 레짐 × 전략 적합도 매트릭스

## 포함 범위

현재 페이즈에 포함:

- 분봉 / 일봉 / 거래대금 / 프로그램 매수 기반 분석
- 돌파 이벤트 정의와 성공/실패 자동 라벨링
- 최근 5일 / 20일 / 60일 시장 통계 집계
- 시간대별 돌파 성과 분석
- 시장 상태 분류
- HTML / JSON 대시보드
- 키움 기반 실시간 / 준실시간 수집 연결

다음 페이즈에 포함:

- 눌림 / 상따 / 종베 / 스윙 각각의 1단계 + 2단계
- 전략 간 비교 인터페이스
- 백테스트 결과 누적

## 비포함 범위

이 프로젝트가 하지 않는 것:

- 완전 자동매매
- 주문 체결 엔진
- 초단타 체결 최적화
- 딥러닝 기반 예측 모델 우선 개발

## 성공 기준

프로젝트가 유의미하다고 볼 기준:

- 1단계: 최근 1주일 돌파 성공률을 시장 전체 기준으로 자동 집계할 수 있다
- 1단계: 오늘 시장이 돌파 우호장인지 함정장인지 명확하게 분류할 수 있다
- 2단계: 1단계 regime에 따라 같은 종목이 다른 action 라벨을 받는다
- 2단계: 사용자가 장중 판단 전에 "오늘 들어가도 되는 종목인가"를 참고할 수 있다
- 확장: Phase 2 전략 추가 시 1단계/2단계 인터페이스 변경 없이 모듈만 갈아끼우면 된다

## 사용자 관점 출력

현재 페이즈 핵심 출력:

- 오늘 시장 상태: `돌파 우호 / 중립 / 함정`
- 최근 1주일 돌파매매 성공률
- 최근 1주일 돌파매매 평균 기대수익
- 시간대별 유리한 돌파 패턴
- 최근 잘 되는 / 피해야 할 돌파 유형
- 1단계 regime을 반영한 종목 카드 (actionable / stalk / watch / too_extended / avoid)

다음 페이즈 출력:

- 전략별 시장 상태 한눈에 보기
- 전략별 추천 종목 카드
- 오늘 가장 유효한 전략 비교

## 개발 우선순위

1. **1단계 시장 판정 로직 정식 구현** (현재 가장 큰 결손)
   - 돌파 이벤트 자동 라벨링
   - 시장 전체 기준 통계 자동 집계
   - 시장 상태 분류기
2. **1단계 → 2단계 결합 강화**
   - regime이 컷오프와 가중치를 직접 변경
   - 가산/감점 방식 폐기
3. 2단계 인터페이스 설명력 강화 (왜 이 종목이 actionable인가)
4. 장중 실시간 수집 검증 마무리
5. Phase 2 다전략 확장을 위한 1단계 / 2단계 인터페이스 추상화
