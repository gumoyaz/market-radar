# Roadmap

## Phase 1

현재 페이즈의 목표는 `돌파매매`를 위한 로직과 인터페이스를 설계하는 것이다.

핵심 산출물:

- 돌파매매 정의 문서
- 돌파매매 이벤트 라벨링 규칙
- 최근 돌파 트렌드 리포트
- 돌파 중심 시장 상태 대시보드
- 돌파매매 판단용 인터페이스 초안

### Phase 1에서 보고 싶은 질문

- 최근 1주일 돌파매매 성공률은 어떤가
- 어떤 돌파 패턴이 잘 먹히는가
- 어떤 시간대의 돌파가 유리한가
- 오늘 시장은 돌파 친화장인가
- 어떤 돌파는 피해야 하는가

## Phase 2

다음 페이즈에서 전략 범위를 넓힌다.

확장 전략:

- 눌림목
- 종베
- 상따
- 스윙

핵심 산출물:

- 전략별 정의 문서 확장
- 전략별 성공률 리포트
- 전략 간 비교 대시보드
- 시장 레짐별 전략 적합도 해석

### Phase 2에서 보고 싶은 질문

- 최근 시장에서 돌파보다 눌림이 더 좋은가
- 상따가 유효한 장인가
- 종베가 먹히는 장인가
- 스윙으로 이어질 만한 주도 흐름이 있는가

## Phase 3

전략 로직이 안정되면 자동화와 학습을 붙인다.

- 전략별 백테스트 자동화
- 장마감 리포트 자동화
- 지속학습 파이프라인
- 시장 상태 자동 요약
- 실시간/준실시간 모니터링 강화
